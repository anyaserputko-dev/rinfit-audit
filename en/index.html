Stock

Negative inventory

Some variants sit at −1 and −3: more was sold than the system had. Site and warehouse disagree — worth reconciling before showing availability to shoppers.

Process

The theme lives on GitHub

Your live theme Rinfit/live is connected to a private repository. That is a good thing: changes go through a branch and a review, nothing breaks in production. We work the same way.
